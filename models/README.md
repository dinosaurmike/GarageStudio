# 3D CAD models (optional)

Garage Studio can show manufacturer CAD models of the connectors and screws it uses (for example the RTC2Z
corner, RTT22Z T, RTA2Z angle, RTU2 U-bracket, LUS24 hanger, Strong-Drive SD screws and Titen HD anchors).
Those STL files belong to their manufacturer, so they aren't included in this repository.

To use them, download the STL drawings from the manufacturer's site
(<https://www.strongtie.com/search?v=%3Arelevance%3AdrawingFileType%3ASTL&tab=drawing>) and put them in this
folder with their original file names (for example `C_RTC2Z_3d_Cad_MULT_Prod.stl`). Without them, the app draws
its own simplified versions of the parts.
